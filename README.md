# create-ubuntu-mate-custom-live-iso_1.6_all.deb
Builds a bootable **Ubuntu MATE live ISO** from the system you are currently running (UEFI and legacy BIOS, LightDM autologin, Calamares installer 26.04, Ubiquity installer 22.04, desktop and server), and includes a small launcher to test the resulting ISO in a QEMU virtual machine.
